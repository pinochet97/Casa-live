# Modelos de entrega

Use estes formatos. Salve as entregas de clientes na pasta do cliente no Drive (`08 Clientes/<Marca>/`).

## 1. Plano de live (uma sessão)
```
PLANO DE LIVE — [Marca] — [data] [hora início–fim] — ID [CL-AAAA-NNN]
Conta: @[conta] | Host: [nome] | Moderador: [nome] | Cenário: [x]
Objetivo: [ex.: GMV R$ X / testar herói Y / testar horário]
Formato: [vitrine rotativa / herói / desafio / leilão]

PRODUTOS (ordem): 
 1. [produto de entrada] — R$ normal / R$ live — item nº — estoque
 2. [herói] — ...
 3. ...
RELÂMPAGOS: [hora] [produto] [preço] [qtde] | [hora] ...
BRINDE/CUPOM: [regra]
GANCHO DE ABERTURA: "[fala]"
CRONOGRAMA:
 00:00 abertura | 00:05 produto 1 | 00:25 produto 2 | 00:40 RELÂMPAGO 1 | ...
OBJEÇÕES PREVISTAS + RESPOSTAS: ...
NÃO PODE DIZER: ...
AQUECIMENTO: vídeos [D-2, D-1, D-0], evento de live agendado [sim/não]
```

## 2. Pacote de vídeos curtos (por produto)
```
PRODUTO: [nome] | PREÇO: R$ [x] | PÚBLICO: [x] | DIFERENCIAL: [x]
GANCHOS (5): 1) ... 5) ...
ROTEIRO A (PAS): [falas com tempos]
ROTEIRO B (Demonstração): ...
ROTEIRO C (Lista): ...
TEXTO NA TELA: ...
LEGENDA + HASHTAGS: ...
TESTE: gravar A com os ganchos 1, 2 e 3 → comparar em 72 h
```

## 3. Diagnóstico de live (pós-live)
```
LIVE [ID] — [Marca] — [data]
NÚMEROS: duração | espectadores | pico (hora) | tempo médio | cliques | pedidos | GMV | GPM | conversão
O QUE FUNCIONOU: ...
O QUE NÃO FUNCIONOU (sintoma → causa provável, tabela da seção 8 do live.md): ...
DECISÃO: MANTER [1] | MUDAR [1] | TESTAR [1]
```

## 4. Diagnóstico de conta (onboarding) — seguir a seção 1 do `estrategia-conta.md`
Saída: tabela de áreas com status (✅/⚠️/❌), ajustes priorizados (top 5) e o produto herói escolhido.

## 5. Briefing de creator — seção 5 do `creators-afiliados.md`

## 6. Treinamento rápido de host (para vendedor novo)
```
1. Leia: live.md seções 4, 5 e 9 + ficha dos produtos do cliente
2. Ensaio de 20 min gravado: abertura + 1 ciclo completo + 1 relâmpago
3. Avaliação (nota 0-100, doc 20-operacao-live): clareza 25 | fidelidade à ficha 20 | objeções 15 | energia 15 | preparo 15 | categoria 10
4. Aprovado com ≥ 75 e nenhum erro de compliance
```

## 7. Registro de aprendizado (aprendizados.md)
```
## [data] — [Marca] — [live/vídeo/creator]
Contexto: ...
O que testamos: ...
Resultado (números): ...
Lição: ...
Aplicar em: [outros clientes/categorias]
```
