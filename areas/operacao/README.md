## Como usar esta sessão
- "Montar agenda de <marca> para <mês>" → o Claude preenche as linhas na Agenda e confere os alertas.
- "Ficha do produto <X>" → envie as fotos e informações e o Claude monta o rascunho para o cliente aprovar.
- "Roteiro da live de <marca> em <data>"
- "Registrar live: <dados ou print>" → o Claude preenche o Registro e gera o relatório D+1.
- "Relatório semanal de <marca>" → o Claude usa a aba Resumo semanal.
- "Chegaram amostras da <marca>" + fotos → o Claude registra na aba Amostras.
