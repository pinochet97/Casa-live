# 🎬 Operação

**Escopo:** estúdio, hosts, agenda, fichas de produto, roteiros, execução das lives, registro, relatórios D+1, semanal e mensal, vídeos curtos (etapas E4 a E7).

**Regras:** `docs/20-operacao-live.md` e `docs/30-relatorios-kpis.md`.

**Dados:** planilhas "Casa Live — Agenda" e "Casa Live — Registro de Lives" (Drive, pasta 04).

**Como usar:**
- "Montar agenda de <marca> para <mês>"
- "Ficha do produto <X>" → envie as fotos e informações e o Claude monta o rascunho para o cliente aprovar.
- "Roteiro da live de <marca> em <data>"
- "Registrar live: <dados ou print>" → o Claude preenche o registro e gera o relatório D+1.
